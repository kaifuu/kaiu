# 系统功能搭建方案

> 依据 `doc/req/` 下两份需求文档编制：
> - 《晖鸿厂区巡检无人机 · 技术参数要求》（下称**需求 A**）
> - 《仿真反无人机系统 · 解决方案》（下称**需求 B**）
>
> 本方案给出系统功能的模块划分、建设内容、数据支撑、接口对接与分期实施路径。

## 一、方案概述

### 1.1 建设背景

| 需求 | 业务定位 | 核心诉求 |
|---|---|---|
| **需求 A** 厂区巡检无人机 | 面向晖鸿厂区的**常态化无人机自动巡检**（机场 + 无人机 + 气体检测载荷） | 自动巡飞采集 → 环境/气体监测 → AI 识别风险 → 事件与工单闭环 → 一体化预警 |
| **需求 B** 仿真反无人机 | 面向公安/安防/军工实训的**反无业务仿真演练**（纯仿真，零空域风险） | 遥控器操控仿真入侵 → 探测感知 → 声光告警 → 联动反制 → 复盘推演 |

两者业务目标不同，但**底层能力高度重合**：设备接入与管理、电子围栏、告警管理、地图态势、审计日志、RBAC 权限、可视化大屏。

### 1.2 建设目标

1. **一套平台底座，两个业务子系统**：公共能力（设备/告警/围栏/地图/权限/审计/大屏）一次建设、双系统复用，避免重复投入。
2. **需求 A 全条款覆盖**：从硬件接入到一体化预警平台的完整链路可交付、可验收。
3. **需求 B 独立闭环**：仿真操控—探测—告警—反制—复盘全链路可推演、可回放。
4. **标准接口与第三方集成**：与环境监管平台、视频监控系统、GIS 平台对接。

### 1.3 系统关系

```
                    ┌──────────────────────────────────┐
                    │        统一平台底座（复用层）      │
                    │  RBAC 权限 · 审计日志 · 地图服务   │
                    │  设备管理 · 告警中心 · 大屏可视化  │
                    │  AI 算法引擎 · 文件/媒体 · 消息推送 │
                    └───────────┬──────────┬───────────┘
                                │          │
                ┌───────────────▼──┐    ┌──▼────────────────┐
                │ 子系统 A          │    │ 子系统 B           │
                │ 厂区巡检无人机系统 │    │ 仿真反无人机系统    │
                └──────────────────┘    └───────────────────┘
```

## 三、子系统 A：厂区巡检无人机系统

### A1 设备接入与选型（需求 2.1–2.5）

**功能内容**

| 模块 | 关键指标要求 | 落地要点 |
|---|---|---|
| 无人机 | 起飞重量 ≤4kg；最大信号距离 ≥15km；续航 ≥40min；抗风 ≥6 级；IP55；RTK 悬停 ≤0.1m | 接入后登记机型档案，遥测字段与物模型对齐 |
| 云台相机 | 可见光 4000 万 ×2（广角+长焦）、变焦 ≥100 倍；红外 640×512@30Hz；三轴增稳；4K30p | 媒体文件按「架次 → 通道 → 文件」组织，支持红外/可见光配对 |
| 机场 | IP56；作业半径 ≥10km；降落风速 12m/s；内置 RTK；O3 图传；4G+以太网；防雷+水浸 | 机场在线状态、舱盖、温湿度、网络链路纳入设备监控 |
| 气体检测仪 | ≤110×80×80mm、≤250g；扩散式；温湿度/PM2.5/PM10/恶臭八项（GB14554-93） | 按国标加权算法折算**恶臭指标值**，作为独立监测指标入库 |

**功能点**

- 设备全生命周期管理：新增、入网注册、状态监测、参数配置、固件适配、离线维护、注销
- 设备健康告警：离线、低电量、HMS 故障码、链路中断
- 气体检测仪数据回传：实时值 + 断点续传（网络恢复后补齐，不影响实时通道）
- 状态指示与数据加密：通讯链路加密，设备状态可视化（电量/充电/工作指示灯）

### A2 飞行控制与任务管理（需求 2.6.1）

- **航线规划**：地图绘制航点、高度/速度/航向设置、避障策略、模板化航线
- **计划与任务**：飞行需求申请 → 航线绑定 → 计划制定（周期/单次）→ 任务下发 → 执行监控
- **飞行监控**：实时位置、高度、速度、姿态、电量、卫星数、剩余里程
- **控制能力**：一键起飞、自主航线飞行、人工接管、自动返航、任务中止
- **架次归档**：每次执行生成架次记录（起止时间、时长、里程、媒体数、告警数）

### A3 风险识别与事件管理（需求 2.6.2 + 2.8）

**算法能力矩阵**

| 算法 | 需求条款 | 识别目标 | 输出 |
|---|---|---|---|
| 烟火识别 | 2.8.1 | 明火、烟雾、异常高温点 | 告警 + 高温点坐标 |
| 臭气检测与溯源 | 2.8.2 | 恶臭浓度异常 | 告警 + 扩散轨迹模拟 + 反向溯源泄漏源 |
| 非法倾倒识别 | 2.8.3 | 厂区内非法倾倒行为 | 告警 + 录像取证 |
| 覆盖膜异常 | 2.8.4 | 填埋库覆盖膜破损/掀起 | 告警 + 图像标注 |
| 烟囱排放监测 | 2.8.5 | 白烟（水蒸气）与黑/灰/紫/浓黄异常烟羽 | 告警 + 自动录像取证 + 发现时间 |
| 液体泄漏检测 | 2.8.6 | 路面含盐废水、罐区/围堰、可燃废液泄漏 | 告警 + 泄漏位置 |

**事件闭环**

异常上报 → 事件建档（热力图展示）→ 工单派发 → 处置跟踪 → 办结归档。

- 高浓度/高风险分级配色展示，预警值可自定义
- 事件热力图按时间/区域聚合，支持多维检索

### A4 气体监测与污染扩散（需求 2.4、2.8.2）

- 监测点分布地图 + 实时浓度列表（多气体同时显示）
- **浓度栅格图**：按监测轨迹插值绘制污染浓度分布
- **扩散模拟与溯源**：结合实时风速风向，动态模拟污染物扩散轨迹并反向定位泄漏源/逸散区
- 历史曲线：各点位浓度趋势，支持导出（留存 ≥6 个月）
- 风场信息：按监测时段关联风场数据

### A5 数据展示与"一张图"（需求 2.6.3）

- 环境监测数据**实时同步**：大屏 + PC 端 Web 双端展示
- 统计报表：日/周/月监测次数、时长、里程
- 地图能力：点位分布、监测轨迹、轨迹上叠加气体浓度、多气体实时数据
- 多形态呈现：浓度栅格、曲线图、实时数据列表
- 环境信息：气压、温度、湿度、风速、风向、空气污染指数
- 飞行信息：时间、监测时长、卫星颗数、高度、里程、速度、剩余电量

### A6 历史记录与报告（需求 2.6.4）

- 记录名称按起始点信息自动生成
- 历史检索：关键词、日期、组织、SN 多条件组合
- 记录详情：浓度曲线、浓度栅格、设备信息、风场信息
- 数据操作：编辑、删除、导出、导入、合并
- **监测报告一键生成**：PDF / Excel 格式，PDF 含气象数据，支持在线填写 AI 结论性监测意见

### A7 成果与媒体管理（需求 2.6.6）

- 巡检视频、照片、三维模型、全景影像的存储、检索、下载
- 成果发布、共享与权限管理
- **成果一张图**：集成任务、航班、事件、资源多维信息
- 巡检报表自动生成

### A8 一体化预警平台（需求 2.9）

**三级风险预警**

```
数据源：气体浓度 / 温度异常 / 目标识别结果
   ↓
动态阈值预警模型（依据历史巡检数据 + 温湿度等环境条件自动调整阈值）
   ↓
风险评估模型
   ↓
一般 ── 较大 ── 重大  三级预警 + 针对性处置建议
```

- **液体泄漏检测**：构建样本数据集，基于深度学习模型训练优化，实现实时检测
- **误报/漏报抑制**：动态阈值随环境自适应，降低误报率与漏报率
- 告警规则自定义、分级告警、实时推送
- 任务管理、告警管理、地图显示、信息查询、报表导出

### A9 权限与安全（需求 2.6.5）

- 系统日志审计、操作追溯、异常行为告警
- 用户管理：添加、删除、修改
- 角色权限：按角色配置功能权限
- 组织管理：子组织新增与权限管理
- 安全机制：控制权分离、设备健康告警、安全设置

### A10 接口与第三方集成（需求 2.7）

| 对接对象 | 内容 |
|---|---|
| 环境监管平台 | 标准数据接口，监测数据与告警信息同步 |
| 视频监控系统 | 厂区现有视频系统集成（通道复用、画面联动） |
| GIS 平台 | 地图底图、坐标体系、空间数据互通 |

## 四、子系统 B：仿真反无人机系统

### 4.1 三层架构

```
第一层 操控仿真层    实体遥控器 → 遥控信号采集 → 仿真无人机模型
                    输出：实时位置、高度、航向、速度
                              ↓ 目标轨迹数据
第二层 探测预警层    仿真探测单元 → 多源融合识别、定位、入侵区域判定
                    输出：入侵告警事件、目标坐标
                              ↓ 告警事件 & 目标信息
第三层 联动反制层    主控平台内核（规则引擎、态势展示、数据存储）
                    声光告警模块（声音 + 红光闪烁）
                    仿真反制模块（干扰 / 迫降动效仿真）
```

### B1 无人机手动遥控入侵仿真

- **实体遥控器直连操控**，完全复刻真实操控逻辑：前后、左右、升降、旋转
- 操控延迟 ≤20ms，操控手感贴合真实无人机
- 典型入侵场景：直线入侵、绕行潜入、定点滞留、低空突防
- 参数自定义：飞行速度 0–30m/s 无级调节、高度 0–1000m 仿真可调、滞空时间
- 机型适配：多旋翼小型无人机、轻型工业无人机仿真模型
- 全程飞行状态实时可视化

### B2 全域探测感知仿真

- 仿真雷达探测、射频探测、光电探测多源融合
- 可自定义：探测防控区域、探测灵敏度、识别阈值
- 自动完成：目标捕捉 → 坐标定位 → 轨迹追踪 → 入侵判定
- 精准区分正常空域飞行与违规入侵行为
- 探测范围缩放，模拟复杂电磁环境下的探测效果
- **指标**：最大仿真探测距离 5000m；响应 ≤300ms；定位精度 水平 ±5m / 高度 ±8m；可识别频段 433MHz / 868MHz / 915MHz / 2.4GHz / 5.8GHz

### B3 智能声光告警

- 触发探测阈值后**全自动**启动声光告警
- 软件界面弹窗预警：入侵时间、无人机位置、飞行轨迹
- 硬件声光：警示音量 ≥110dB，红光闪烁
- 告警响应延迟 ≤100ms

### B4 联动反制动效打击

- 告警触发后自动联动反制设备，支持手动/自动两种模式
- 反制类型：信号压制、频段干扰、导航欺骗、强制迫降、空中驱离
- **动效呈现**：无人机姿态失控 → 航线偏移 → 干扰成功打掉
- 有效反制仿真距离 0–3000m 可调；反制响应 ≤500ms；生效时长 1–3s
- 验证"探测—告警—反制"设备联动时效与协同能力

### B5 数据记录与复盘

- 全程自动记录：飞行轨迹、入侵时段、探测响应时间、告警触发时长、反制启动时效、处置结果
- 轨迹回放 + 流程复盘
- 用于：防控预案优化、人员处置能力考核、设备联动逻辑校验

### B6 场景自定义拓展

- 自定义防控区域大小、探测阈值
- 多地区仿真防控环境搭建
- 适配不同行业低空安防演练需求

### B7 态势可视化

- 设备空间分布、在线状态、空域目标态势、实时飞行轨迹、告警事件、联动处置记录
- 在线/离线地图切换、地图测距标记、图层控制
- 目标轨迹回放、事件精准查询、数据统计分析、证据预览导出、运维台账管理

### B8 设备管理

- 仿真探测、仿真反制全品类设备统一管理
- 全生命周期：新增、入网注册、状态监测、参数配置、固件适配、离线维护、注销

### B9 设备协同联动

- 可视化联动编排：演练流程自定义、联动逻辑可视化编排、仿真策略模板固化
- 三大核心演练场景：
  1. **仿真身份取证管控演练**：身份识别 → 画面取证 → 违规干预
  2. **频谱特征识别与定向干预演练**：目标信号识别 → 轨迹跟踪 → 精准压制推演
  3. （预留）多设备协同拦截演练

### B10 反制指令闭环监控

- 依托统一设备管理底座，实现反制指令全生命周期监控
- 解决"指令下发无反馈、仿真执行不可视、异常问题无记录"短板
- 指令状态流转：已下发 → 执行中 → 已生效 / 失败，全程留痕

### B11 电子围栏管理

- GIS 地图交互式绘制**圆形、多边形**禁飞区域，自定义区域名称
- 实时监测仿真无人机轨迹，自动判定是否闯入禁区
- 精准触发入侵告警与联动反制逻辑
- 围栏全流程运维：新增、编辑、删除
- 适配单点禁区、多点禁区、多层级防护场景

### B12 黑白名单管理

- 基于无人机 SN 码的精细化管控
- 功能：新增、修改、删除、批量查询、临时配置
- **临时白名单有效期**：到期自动失效，无需人工操作
- 快速比对判定目标属性，过滤合法目标无效告警，降低误警/虚警率

### B13 告警管理

- 全流程闭环：数据采集 → 实时推送 → 持久化存储 → 多维检索 → 可视化展示 → 统计复盘
- 告警详情：SN 码、违规闯入区域、触发时间、目标高度速度、飞行态势
- 数据永久留存，支持按时间、设备、区域、目标类型组合检索
- 自动生成：告警统计、事件分布、处置效率分析报表

### B14 地图管理

- 地图源：在线电子地图、卫星影像地图、离线地形图多类型切换
- **坐标系自动统一转换**，保证设备点位、禁飞围栏、航迹坐标精准匹配
- 基础操作：平移、缩放、全屏、测距测面积、点位标记
- 点位弹窗详情：设备参数/在线状态；目标实时坐标、姿态、航迹、威胁等级
- 缓存优化与加载容错：资源预加载、异常重试，保障 7×24 稳定
- 结合权限体系实现地图敏感操作权限隔离

### B15 硬件资源监控

- 服务端与集群硬件资源监控：计算资源、节点状态、磁盘存储、网络链路
- 可视化：CPU、内存占用率、节点健康度、磁盘利用率、网络联通状态
- 自定义监控 IP、端口、资源告警阈值
- 超限/异常/中断自动触发后台告警

### B16 审计日志管理

- 覆盖：用户登录退出、场景配置、参数修改、设备启停、仿真指令下发、联动策略编辑、告警处置、台账导出

- 加密存储、长期留存、不可篡改

### B17 用户身份与访问控制

- 基于 **RBAC** 角色权限模型：身份认证 + 角色授权 + 数据隔离
- 用户管理：全生命周期管理、密码加密存储、密码复杂度校验
- 角色管理：自定义配置、权限绑定、职责划分
- 权限管理：**功能权限 + 区域数据权限**双层管控

## 七、接口与集成

### 7.1 设备接入协议

| 对象 | 协议 |
|---|---|
| 无人机/机场 | DJI 上云 API（MQTT 上行遥测 + HTTP 下发指令） |
| 气体检测仪 | 4G/5G 无线传输，加密链路，支持断点续传 |
| 仿真遥控器 | 串口/USB HID → 信号采集服务 → 内部消息总线 |
| 仿真探测/反制 | 内部服务调用（仿真动效由前端渲染驱动） |

### 7.2 对外集成

- **环境监管平台**：标准数据接口，推送监测数据与告警
- **视频监控系统**：GB28181 / RTSP 通道对接
- **GIS 平台**：底图服务、坐标转换、空间数据
- **统一鉴权**：Token 机制，支持对接上级平台单点登录

### 7.3 接口规范

- 统一响应包装 `{ code, msg, data }`
- 列表统一分页：`page` / `size` / `sortBy` / `direction` / `keyword`
- 鉴权：`Authorization: Bearer <token>`
- 实时推送：WebSocket（告警、遥测、指令状态）

## 十一、验收要点

1. **功能完整性**：第 10 章对照表逐条演示，无遗漏条款
2. **性能指标**：操控延迟 ≤20ms、探测响应 ≤300ms、告警 ≤100ms、反制 ≤500ms、全链路 ≤500ms
3. **闭环可验证**：巡检链路（任务下发→飞行→识别→告警→工单→办结）与仿真链路（入侵→探测→告警→反制→复盘）均可完整演示
4. **数据留存**：监测数据 ≥6 个月，告警与审计日志长期留存且不可篡改
5. **接口联调**：环境监管平台、视频监控、GIS 三方对接实测通过
6. **稳定性**：7×24 连续运行无中断，地图与推送具备容错重试
7. **安全合规**：RBAC 权限分级、数据隔离、密码加密、链路加密
8. **文档交付**：部署手册、操作手册、接口文档、测试报告
